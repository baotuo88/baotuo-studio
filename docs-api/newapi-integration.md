# 历史 New API 集成（已停用）

baotuo-studio 不再捆绑部署 New API 或 newapi-video-helper，两份 Docker Compose 均不包含这些服务。部署、构建、拉取镜像和启动不需要网关。

模型由管理员在项目后台的“模型渠道”中配置：接口地址、API Key、协议、模型 ID；然后在“模型能力与计费”中设置模型类型、能力、参数及默认项。

此目录中的协议插件为上游历史源码，保留供参考，不参与当前部署。旧插件专有协议需要改为项目已有直连适配器，或配置自定义请求模板；不要再执行旧网关安装和迁移脚本。

详见项目根目录 `docs/custom-model-channels.md`。
